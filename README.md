# SafeText AI 🛡️


## the  text to paste in termunal to run this is:- npm run dev:all




SafeText AI is an AI-powered scam message detection platform.

It analyzes suspicious messages, detects scam patterns and URLs, calculates a risk score, and explains why a message may be dangerous.

## 🚀 Features

- 🤖 AI-powered message analysis
- 🔍 Scam and suspicious message detection
- 🔗 Suspicious URL detection
- 📊 Risk score and threat category
- 💡 AI-generated explanation
- 🕘 Scan history with search and filters
- 📈 Dashboard with scan statistics
- 🔐 Secure user authentication
- 👥 User-specific scan history
- ⚠️ Error handling and loading states

## 🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Python
- AI API
- URL Analysis

## 🔄 How It Works

1. User logs in to SafeText AI.
2. User enters a suspicious message.
3. The AI analyzes the message and detects scam indicators.
4. URLs inside the message are analyzed.
5. A risk score and scam category are generated.
6. The result and explanation are shown to the user.
7. The scan is saved to the user's history.
